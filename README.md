Organization_Akhmarov
WPF приложение для управления складом с учетом товаров.

- Управление организациями
- Управление складами
- Управление товарами
- Импорт товаров из CSV
- Партионный учет через накладные
- Unit-тесты для сервисов

Технологии C# / WPF / .NET 8.0 MVVM NUnit (Unit-тесты)

Для запустить приложения откройте Organization_Akhmarov.sln, затем в обозревателе решения запускайте Organization_Akhmarov.WPF
